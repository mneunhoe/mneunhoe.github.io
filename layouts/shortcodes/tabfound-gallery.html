{{- /* The tabfound architecture gallery: every model in every style, detail and theme, and every pair side by side, with controls to pick the view. Figures and figures/manifest.json are page resources, synced from tabfound by scripts/sync-tabfound-gallery.sh. The words come from data/tabfound_gallery.yaml. Every file the manifest names is looked up here, so a missing figure fails the build instead of showing a broken image. */ -}} {{- $page := .Page -}} {{- $manifestRes := $page.Resources.Get "figures/manifest.json" -}} {{- if not $manifestRes -}} {{- errorf "tabfound-gallery: %s has no figures/manifest.json;
